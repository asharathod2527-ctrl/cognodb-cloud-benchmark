# Benchmark Results

Benchmark results will be added after the experiments are completed.

Each database will be evaluated using the same dataset, logical workloads, client machine, and comparable resources.

## Metrics

- Data loading throughput
- 1-hop traversal latency
- 2-hop traversal latency
- 3-hop traversal latency
- Point lookup latency
- Indexed/filtered lookup latency
- Aggregation latency
- Concurrent read/write throughput
- Observable resource usage

Results will report p50 and p95 latency where applicable.
